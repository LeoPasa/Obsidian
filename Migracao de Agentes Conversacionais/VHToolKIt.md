Plataforma de criação de humanos virtuais voltado para Unity Engine.Possui integração de customização de IA, junto de SUPORTE multi-plataformas. Incluindo **celulares**.

Possui a plataforma RIDE integrada.(pacotes com integrações nativas de IA)

# Requisitos
- [x] Unity (Algo a partir de 6000.1)
- [x] Virtual Studio 2022
- [x] JetBrains Rider
# Como começar
Bem... ate agora, só 
- abrir o projeto VHUnityURP (e só uma amostra de projeto mas pode ajudar já).
- Abrir e dar "play" na cena Assets/Scenes/SampleScene (no fim, n ta no SampleScene, é só no Assets/Scenes)
- Para funcionar efetivamente, é necessário:
	-  API keys e colocar dentro de um .json (ride dentro de config. É possivel acessar dentro da Unity)
	- Ou uso de LLM local.
